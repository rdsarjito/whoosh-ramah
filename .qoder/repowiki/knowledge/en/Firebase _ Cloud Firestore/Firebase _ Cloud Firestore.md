### Identity
Google Cloud Firebase — used as both the real-time database and the auth boundary.

### Role in this repo
- **Flutter side** (`whoosh_ramah`): `firebase_core` + `cloud_firestore` read/write the `permintaan_pendampingan` collection via `PermintaanService`. `lib/firebase_options.dart` is generated by `flutterfire configure` and must not be edited.
- **Detector side** (`detector/`): `firebase-admin>=6.4` (Python) writes task documents created by the YOLO-World camera pipeline.

### Integration notes
- Security rules are open (`allow read, write: if true`) — demo-only, not production.
- The detector writes only a subset of fields (`jenisBantuan`, `titikJemput`, `status`, `sumber`, `idKamera`, `keyakinan`, `namaPenumpang=null`, `dibuatPada`); the Flutter `fromFirestore` must treat `riwayat`, `diperbaruiPada`, `idPenumpang`, `kereta`, `gerbong`, `kursi`, `catatan`, `petugas` as nullable.
- Verify exact Firestore field names against `detector/detect_wheelchair.py` before changing the schema.
