Three children converge on one contract: the `permintaan_pendampingan` collection in Cloud Firestore (field names, enums for `jenisBantuan` and `status`, plus the `riwayat` array) defined in PROJECT.md. The `wheelchair_detector` child writes documents into this collection (with `sumber: kamera_ai`), while the `whoosh_ramah_app` child streams them via `cloud_firestore` and renders role-based screens (Penumpang/Petugas/Keluarga). The `design_docs` child provides the HTML/CSS reference that both the Flutter UI and the detector's camera window mimic. There is no runtime wiring between children — they communicate exclusively through Firestore, so the schema in PROJECT.md is the single cross-child boundary.
