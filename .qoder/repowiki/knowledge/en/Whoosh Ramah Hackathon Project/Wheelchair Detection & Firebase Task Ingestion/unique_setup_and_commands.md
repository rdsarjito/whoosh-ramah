Requires Python 3.10+ and a local venv (`python -m venv venv && pip install -r requirements.txt`). Two run modes: `python detect_wheelchair.py --tanpa-firebase` for offline demo, or with `firebase-key.json` present to post to Firestore. Training is done in Google Colab via `!python train_yolo.py` and the resulting `models/kursi_roda.pt` is then referenced through `MODEL_LOKAL` in `.env`.
