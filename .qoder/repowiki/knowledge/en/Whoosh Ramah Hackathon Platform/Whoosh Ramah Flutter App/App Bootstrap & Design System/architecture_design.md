Three top-level files form the app's bootstrap layer:
- `main.dart` defines the `WhooshRamahApp` `StatelessWidget`, which is the single root of the widget tree. It wires `Firebase.initializeApp` with `DefaultFirebaseOptions.currentPlatform` before calling `runApp`, then returns a `MaterialApp` whose `home` is `PilihPeranScreen` (role-selection screen) and whose theme is `AppTheme.light`.
- `firebase_options.dart` is generated by the FlutterFire CLI; it exposes `DefaultFirebaseOptions.currentPlatform` and currently only supports Android (other platforms throw `UnsupportedError`).
- `theme.dart` centralizes the visual design system in four static-only classes (`AppColors`, `AppRadius`, `AppShadows`, `AppTheme`) built on Material 3. `AppTheme.light` composes a `ColorScheme.fromSeed` overriden with role-specific colors (red for passengers, blue for officers, green for family), a custom `TextTheme` using the bundled Nunito font, and default `ElevatedButtonThemeData` / `OutlinedButtonThemeData` styles.
Dependency direction is one-way: `main.dart` imports both `firebase_options.dart` and `theme.dart`; screens import `theme.dart` but never the bootstrap files. The module has no runtime state — it is purely declarative configuration consumed by the rest of the app.
