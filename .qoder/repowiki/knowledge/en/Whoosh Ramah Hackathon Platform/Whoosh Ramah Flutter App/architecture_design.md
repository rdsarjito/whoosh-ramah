Concentric Dart import layers under `lib/`: `app_shell` (`main.dart`, `theme.dart`) initializes Firebase via `firebase_options.dart` and owns the single `MaterialApp`; `shared_layers` (models, services, widgets) publishes the `Permintaan` domain model plus its `PermintaanService` (Firestore CRUD + demo fixtures) and reusable UI components; `penumpang_flows` implements passenger screens that consume both the shell's theme and the shared layers. The Android native entry point is the standard Flutter-generated activity with no custom logic beyond the plugin registrant, so all orchestration lives in Dart imports — there is no runtime dependency injection or event bus between children.
