Each `.dc.html` file is an independent, self-contained screen mockup rendered by the Kanvas designer runtime. Files follow a fixed structure: `<x-dc>` root wrapping a `<helmet>` with inline styles and Google Fonts, a single top-level `div` sized to a preview viewport (e.g. 390×844 for mobile, 960×600 for desktop), inline SVG illustrations, and a trailing `<script type="text/x-dc" data-dc-script>` block declaring a `Component extends DCLogic` class whose `renderVals()` returns static data. Screens are linked via plain `<a href="*.dc.html">` anchors (e.g. Main → Penumpang-Tiket, Petugas-Tugas, Keluarga-Pantau; Kamera-AI → Petugas-Tugas). A shared `support.js` is referenced from every page for the Kanvas runtime. The README documents that `{{...}}`, `<sc-for>`, and `<sc-if>` inside these files are Kanvas template directives, not plain HTML.
