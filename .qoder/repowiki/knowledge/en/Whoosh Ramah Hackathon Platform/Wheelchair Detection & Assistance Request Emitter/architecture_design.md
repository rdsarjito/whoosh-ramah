Single-script module (`detect_wheelchair.py`) with two entry points: the runtime inference loop and `train_yolo.py` (Colab-only fine-tuning helper).

- Model abstraction: three classes (`ModelRoboflow`, `ModelLokal`, `ModelYoloWorld`) all expose a uniform `deteksi(frame)` returning `(class_name, confidence, x1, y1, x2, y2, track_id)` tuples; `buat_model()` selects one based on the `MODE_MODEL` env var, keeping the main loop model-agnostic.
- Data pipeline: OpenCV reads frames from a webcam or video file; detections are throttled by `DETEKSI_TIAP_DETIK`. Two emission strategies coexist: Roboflow mode uses a global streak counter + cooldown, while YOLO-local/YOLO-World modes use `PelacakTugas`, a per-track-ID state machine tracking consecutive visibility, last-seen timestamps, and per-ID cooldowns so each person gets at most one task.
- Persistence: `PengirimFirebase` initializes `firebase_admin` once and writes documents into `permintaan_pendampingan` with fields `jenisBantuan`, `titikJemput`, `status`, `sumber`, `idKamera`, `keyakinan`, `jumlahTerdeteksi`, `idLacak`, `namaPenumpang`, `dibuatPada`; it retries up to `PERCOBAAN_KIRIM` times with exponential backoff.
- Verification photo (O1): `PenghapusFoto` runs a daemon thread over a priority queue to delete `permintaan_foto/{idTugas}` docs after TTL; `anonimkan_crop` blurs detected faces via Haar cascade, downscales, pixelates, and JPEG-encodes in RAM only. Startup sweeps stale docs via `sapu_kedaluwarsa()`.
- Configuration: every tuning knob lives in `.env` via `python-dotenv` (confidence threshold, frame persistence, debounce, detection cadence, camera location/id, model path, Roboflow credentials, Firestore key path/collection name).
- Dependency direction: the main loop depends on the model abstraction and the Firebase sender; training code is independent and targets Google Colab with GPU.
