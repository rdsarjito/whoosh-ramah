# Acuan desain

File .dc.html di folder ini adalah desain layar dari kanvas Whoosh Ramah (Gaya B).
Gunakan sebagai acuan tata letak, warna, ukuran huruf, dan sudut membulat.
Semua gaya ditulis inline di atribut style, jadi mudah dibaca.
Bagian {{...}} dan <sc-for>/<sc-if> adalah template kanvas, bukan HTML biasa:
anggap sebagai daftar berulang / kondisi.
