# Paket gaya baru Whoosh Ramah

Taruh isi folder ini di root project (`~/projects/whoosh-ramah/`):

- `design/Contoh-Brightline-Pilih-Peran.dc.html` — acuan gaya baru (layar Pilih peran).
- `design/Logo-C-Kereta-Senyum.dc.html` — lembar logo (cara logo dipakai di berbagai ukuran).
- `logo/logo_kereta.svg` — logo untuk dipakai di dalam aplikasi (latar transparan).
- `logo/ikon_aplikasi_1024.png` — ikon aplikasi penuh (latar merah #E11D2E).
- `logo/ikon_foreground_1024.png` — lapisan depan untuk adaptive icon Android.
